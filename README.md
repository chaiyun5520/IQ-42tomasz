# IQ-42 · กราฟ Forex 5 นาที

เว็บไซต์ไทยสำหรับดูกราฟแท่งเทียน OHLC 5 นาทีของ USD/JPY, GBP/USD และ EUR/THB จาก Twelve Data พร้อม EMA20/50 และ RSI14

## หน้าสาธิต

https://chaiyun5520.github.io/IQ-42tomasz/

## การเชื่อมต่อข้อมูล

หน้าเว็บเรียก Twelve Data `/time_series` ด้วยคีย์ที่กำหนดไว้ใน frontend สำหรับการทดสอบ การเปลี่ยนคู่เงินโหลดข้อมูลคู่เดียวไม่มีการ polling อัตโนมัติ

## ความปลอดภัยสำคัญ

API key ที่ส่งมาถูกใส่ลงใน public repository โดยเจตนาเพื่อทดสอบเท่านั้น ประชาชนสามารถดู key จาก source และดึงไปใช้ได้ ควร **สลับ/ลบ key ทันที** ในบัญชี Twelve Data แล้วใช้ backend proxy หรือ GitHub Actions/เซิร์ฟเวอร์เก็บ secret ในอนาคต

## ข้อจำกัด

- ความพร้อมและความล่าช้าของ EUR/THB ขึ้นกับผู้ให้บริการและแผนบัญชี
- สัญญาณ EMA/RSI เป็นตัวอย่าง ไม่ใช่คำแนะนำการลงทุน
- ไม่เชื่อมต่อ IQ Option หรือส่งคำสั่งเทรดอัตโนมัติ
