# IQ-42 · กราฟ Forex 5 นาที

เว็บไซต์ภาษาไทยแบบ static แสดงกราฟแท่งเทียน OHLC 5 นาทีและคำนวณ EMA20/EMA50 กับ RSI14 จากข้อมูลที่ผู้ใช้ร้องขอจาก Twelve Data รองรับ USD/JPY, GBP/USD และ EUR/THB (การมีข้อมูลจริงขึ้นกับความครอบคลุมและสิทธิ์ของบัญชี API)

## เปิดเว็บไซต์

GitHub Pages: https://chaiyun5520.github.io/IQ-42tomasz/

## ตั้งค่า API

1. สมัครบัญชีและสร้าง API key ที่ [Twelve Data](https://twelvedata.com/).
2. เปิดเว็บไซต์ กด **ตั้งค่า API** แล้ววาง key ของคุณ
3. เลือกคู่เงินและกด **รีเฟรช** เพื่อโหลดแท่ง 5 นาทีล่าสุดจาก `/time_series`.
4. ตรวจสอบข้อความสถานะ/API และข้อจำกัดของแผนบริการ หากคู่ EUR/THB ไม่รองรับหรือโควตาหมด ระบบจะแสดงข้อผิดพลาดจาก API

เว็บไซต์โหลดเฉพาะคู่ที่เลือกเมื่อผู้ใช้กดโหลด ไม่ polling อัตโนมัติ เพื่อลดการใช้โควตา API

## ความเป็นส่วนตัวและข้อจำกัด

- API key ไม่ได้ฝังไว้ใน repository แต่เมื่อเรียก API จากเว็บเบราว์เซอร์ key จะปรากฏใน network request ของเครื่องนั้น และผู้ใช้ที่ควบคุมอุปกรณ์/เบราว์เซอร์ได้อาจเห็นได้ อย่าใส่ key ที่มีสิทธิ์หรือค่าใช้จ่ายสูง และอย่าแชร์ลิงก์/เครื่องที่บันทึก key ไว้
- หน้าเว็บเป็น static public website และไม่ได้ใช้ backend proxy. การปกป้อง key จริงต้องทำ backend/serverless proxy ที่เก็บ secret ฝั่ง server.
- API plan อาจจำกัด real-time access, forex pair coverage, refresh frequency, request quota, CORS หรือการใช้ข้อมูลบนเว็บไซต์ โปรดตรวจสอบเงื่อนไขล่าสุดและสิทธิ์การเผยแพร่ข้อมูลกับผู้ให้บริการก่อนใช้งาน
- แท่งล่าสุดอาจยังไม่ปิดหรือข้อมูลอาจล่าช้า ขึ้นกับผู้ให้บริการและแพ็กเกจ
- สัญญาณ EMA/RSI เป็นเพียงตัวอย่างเชิงเทคนิค ไม่ใช่คำแนะนำการลงทุน ไม่รับประกันผล และเว็บไซต์ไม่เชื่อมต่อหรือส่งคำสั่งซื้อขาย IQ Option
